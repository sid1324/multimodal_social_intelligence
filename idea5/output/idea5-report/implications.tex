\paragraph{Implications for Idea 5.} Analysis 3 keeps the idea but changes how it is tested, in three ways. First, appending rendered maps at inference is dropped: maps add nothing beside RGB frames for six frozen models, although a depth map alone lifts accuracy over text, so the open question is whether fine-tuning lets a model use geometry beyond what it already reads from RGB. We will fine-tune an open model on depth and segmentation inputs and compare it with an RGB-only fine-tune of equal budget. Second, every result will be reported against the controls introduced here: text-only input (42\% on average, up to 55\%), the same frames repeated, and maps from a different item. Third, geometry will be evaluated separately on Proxemics and Privacy items, where spatial vocabulary concentrates, rather than on overall accuracy alone. EgoNormia items scored here are excluded from training and model selection.
