# Original VideoNorms scaffold and shared helpers

This schema-gated implementation predates the Social Genome fallback. No actual
VideoNorms data were available, and no VideoNorms results are claimed. Shared
statistics, plotting, validation and embedding-cache helpers are reused by the
active `analysis/social_genome` pipeline. Keep this package alongside it.

See the [package README](../../README.md) for the current study and how to run it.
